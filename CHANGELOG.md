# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-30

### Added
- Initial release
- Modern Symfony 8 integration using AbstractBundle
- Support for PHP 8.2, 8.3, and 8.4
- Automatic authentication state sharing
- Partial reloads support
- Lazy props evaluation
- Server-side rendering configuration
- PSR-4 autoloading
- Full type safety with PHP 8.2+ type hints
- Vue.js and React support
- Clean API with InertiaInterface

### Features
- Zero-configuration setup
- Automatic user data sharing with frontend
- Support for nested page components
- Redirect helpers
- Global data sharing
- Custom root view templates
- Asset versioning for cache busting
